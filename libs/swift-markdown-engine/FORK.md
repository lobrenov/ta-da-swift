# Ta Da fork of swift-markdown-engine

- Upstream: https://github.com/nodes-app/swift-markdown-engine (Apache-2.0, see `LICENSE`)
- Forked from: `0.13.0`, commit `d1421012aeece640e2c2e47e0e573a93cbe2a420`
- Why: the M1 spike (`docs/archive/mvp-plan.md`) needed changes the engine has no hooks for.

## Removed
- `MarkdownEngineCodeBlocks` and `MarkdownEngineLatex` products (and their HighlighterSwift / SwiftMath dependencies), `Demo/`, `media/`, `.github/`.

## Changes
Every change is marked `Ta Da fork` in the source. Tests: `Tests/MarkdownEngineTests/TaDaForkTests.swift`.

1. **Alternative checkboxes.** `Parser/TaskMarker.swift` defines the accepted markers: `[ ]`, `[x]`, `[X]` plus the [Alternative Checkboxes Reference Set](https://github.com/damiankorcz/Alternative-Checkboxes-Reference-Set). As in GFM and Ta Da's `CheckboxSyntax`, a box follows the list marker after one to four spaces or tabs and needs a space or tab after it; the bullet and ordered-marker caret helpers read it the same way. The `.taskCheckbox` attribute holds the marker character (a `String`) instead of a `Bool`. `TaskCheckboxStyle` maps each marker to an SF Symbol, an optional tint, strikethrough, click transition and right-click menu entry. A `draw` closure, when set, draws every box (on the page and in the menu) instead of the symbols. Struck items' text is `mutedText`.
2. **Checkbox size and spacing.** `TaskCheckboxStyle.sizeScale` and `contentGap` set the box size and its gap from the text. The hidden spacer after `-` is kerned so the box fits the bullet slot.
3. **Bullets by depth.** `ListStyle.bulletSymbolNames` (circle.fill, circle, square.fill, diamond.fill, cycling) and `bulletSymbolScale` replace the fixed `•`.
4. **Tab / Shift-Tab** (`Input/MarkdownListIndent.swift`). These act on every selected list line plus its children. Tab only nests an item under a previous sibling. The edits are whitespace-only and go in one undo group.
5. **Obsidian wiki-link aliases.** `[[Target|alias]]` resolves, links and reports clicks by `Target`. Upstream treats the part after `|` as an opaque id.
6. **Theme.** `MarkdownEditorTheme` is `Equatable` and has `selectionBackground`. The theme sets NSTextView's `linkTextAttributes` and `selectedTextAttributes`. A theme change in `updateNSView` restyles in place, so the editor isn't rebuilt.
7. **Bindings follow SwiftUI updates.** Upstream kept the text binding, `isWikiLinkActive` binding and `onLinkClick` from `init`. An embedder that switches documents by passing a new binding therefore had every later edit written into the first document, and the editor snapped back to the unchanged text. `NativeTextViewCoordinator.refresh` runs on every update. `publish` captures the binding and document when it schedules each async write.
8. **Right-click on a task box.** `NativeTextView.menu(for:)` checks for a box before `super`. AppKit's right-click moves the caret onto the line, which reveals the raw `[ ]` and removes the box. With `NativeTextViewWrapper.onTaskMarkerMenu` set, the click goes there instead of the built-in `NSMenu`: `TaskMarkerMenuRequest` carries the marker, the box's screen rect and a `setMarker` that ignores a box whose text has since changed.
9. **Undo and redo reach the binding.** On macOS 27 a TextKit 2 `NSTextView` doesn't post `NSTextDidChangeNotification` for undo or redo (TextKit 1 does), so an undone edit stayed in the bound text and was saved. The coordinator observes each per-document undo manager and runs `textDidChange` after an undo or redo that didn't trigger it.
10. **Slash commands** (`TextView/Coordinator/NativeTextViewCoordinator+SlashCommand.swift`). A `/` typed at a line start or after whitespace, outside code, opens a query. `onSlashCommandChange` reports it (`SlashCommandState`: the `/query` range, the query, whether it starts the line, and the `/`'s screen rect) as it changes, and `nil` when a space, `/` or caret move ends it. While it's open, `onSlashCommandKey` gets ↑/↓ and ↵/⇥, and esc closes it. `SlashCommandProxy.insert` replaces the `/query` in one undo step and sets the selection. The embedder draws the menu.
11. **Compiler warnings.** `BlockScopedTokenizer` (`let first`), `ContextMenu` (`#selector` for the font panel) and `NativeTextViewCoordinator+TextDelegate` (two unused `blockLatexTokens` locals removed). Not marked in the source.
12. **Serial header tests.** `ScrollingHeaderControllerTests` is `.serialized`: its animation tests spin the main run loop, and run in parallel they miss their targets.
13. **Lists in blockquotes.** A quote line whose content is a list item (`> - [ ] a`, `> 1. b`) is also parsed as one, in `BlockNode.blockquote`'s `items`, and styled as a list item inside the quote: bullet or checkbox, hanging indent and strike, one list level in from the quote's text. The items take the list line height and the quote's line spacing, so the bar stays unbroken. The task and bullet caret helpers accept the `>` prefix, and bullet depth counts from after it. Quoted ordered items keep their source numbers. Return continues a quoted item inside the quote (`> - [ ] `); on an empty one it leaves `> `.
14. **The embedder reaches the text view.** `SlashCommandProxy.textView` is the editor's `NSTextView`, for edits the embedder makes itself (Ta Da's Add Subtask).
15. **Inline bubbles** (`Configuration/InlineBubble.swift`, `Renderer/MarkdownTextLayoutFragment+InlineBubbles.swift`). `InlineCodeStyle.bubble`, or an extension's `bubble(theme:)`, draws a span as a rounded fill (optional 1pt ring and text colour) once per line it wraps onto. The `.markdownInlineBubble` attribute covers the span with its markers; hidden markers are kerned to the bubble's padding plus margin.
16. **Callouts** (`Parser/Callout.swift`, `Styling/MarkdownASTStyler+Callouts.swift`, `Renderer/MarkdownTextLayoutFragment+Callouts.swift`, `TextView/NativeTextView/NativeTextView+Callout.swift`). With `configuration.callouts` set, a quote line `> [!type]` (optionally `+`/`-` and a title) that starts a deeper quote level opens an Obsidian callout over the following lines at its level or deeper. Each line's `.calloutLine` says which panel slices, bars and title parts the fragment draws; the embedder supplies tints and icons. The title's `[!type]` hides behind the icon unless the caret is on the line. A `-` callout's body shrinks to 0.1pt lines unless the caret is in it. A click on a foldable title row outside the title text folds or opens it on screen (`calloutFoldOverrides`, cleared on a document switch). A right-click on a title line goes to `NativeTextViewWrapper.onCalloutMenu` (`CalloutMenuRequest`: set the type or fold sign as one undo step, and ring the callout until `close`). A restyle widens to every quote its paragraphs touch. A theme change also copies `inlineCode`, `extensions` and `callouts`.

## Known upstream test failure
`MarkdownHTMLRendererTests` "bare URLs and emails autolink" fails on macOS 27 before any fork change (`www.example.com` isn't autolinked); it passes on macOS 26. The editor doesn't use the HTML renderer.

## Updating from upstream
Diff this folder against a clean checkout of the base commit to get the fork's patch. Apply it to the new upstream version, then run `swift test --package-path libs/swift-markdown-engine`.
