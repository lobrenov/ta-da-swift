## New
- Right-click text in the editor for a menu of Cut, Copy, Paste, Paste as Plain Text and Select All, with Format, Paragraph and Insert submenus.
- Add Link on selected text: pick a file to link, and the selection becomes the link's text.
- Extract to Task works on selected text (⌥⌘E): the selection becomes a new task, linked in its place.
- A contents rail at the editor's right edge: hover it for the file's headings, the files it links to and the files linking to it. On iPhone, swipe in from the right edge.
- On iPhone, the slash menu opens from the keyboard bar.

## Changed
- The editor's bullets, task boxes, lists in tables and typing font are refined.
- The Mac's daily and week note rows are cards, as on iPhone.
- Delete and Move to Trash are red in the file menu, as Delete Forever is.
