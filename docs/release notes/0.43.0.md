## New
- A formatting keyboard on the iPhone. Tap Aa in the keyboard bar to swap the keyboard for markdown keys: headings, bold, italic, strikethrough, lists, subtasks, quotes, callouts, highlight, code, wikilinks, tables, dividers, outdent, indent and delete. A key lights up when the caret is in its format. Tap ABC to go back to letters.
- Press and hold a key with a corner mark for its options, then slide to one and let go: heading levels, bulleted or numbered lists, subtask states, callout types, inline code or a code block, and wikilink, link or embed.

## Changed
- The iPhone keyboard bar is shorter: undo, redo, `/`, subtask, `#`, `>` and `@` on a checkbox line, Aa and hide keyboard. Bold, italic, code, wikilink, callout, outdent and indent moved to the formatting keyboard.
