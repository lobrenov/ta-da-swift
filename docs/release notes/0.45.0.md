## Changed
- Large folders open several times faster, and typing, lists, Search and the link menu stay quick with thousands of files.
- Files iCloud Drive hasn't downloaded yet no longer hold up opening the folder; they appear as they arrive.

## Fixed
- Deleting a folder that holds only hidden files, such as a .git folder, moves it to Trash instead of deleting it.
- On iPhone, a new or moved file no longer takes the name of a file iCloud Drive hasn't downloaded yet.
- Using the other iCloud version of a file keeps your unsaved edits in a copy.
- Making tasks from a project's subtasks leaves the project as it was when a task can't be made.
- Save It Again keeps the file's name, and saves beside a file that came back instead of over it.
- An image pasted just before quitting is saved in full.
- A folder settings file that can't be read is no longer replaced.
- A file that starts with a byte-order mark keeps its properties.
