# Origin of TaDaMarkdown

TaDaMarkdown is Ta Da's live markdown editor. It started as [swift-markdown-engine](https://github.com/nodes-app/swift-markdown-engine) 0.13.0 (commit `d1421012aeece640e2c2e47e0e573a93cbe2a420`), Copyright 2026 Luca Chen, under the Apache License 2.0. It stays under Apache-2.0 (`LICENSE`, `NOTICE`) and doesn't track upstream.

## Removed from 0.13.0
- The `MarkdownEngineCodeBlocks` and `MarkdownEngineLatex` products (and their HighlighterSwift / SwiftMath dependencies), `Demo/`, `media/`, `.github/`, `CHANGELOG.md` and `CONTRIBUTING.md`.

## Renamed
- Package, product, module and test target `MarkdownEngine` → `TaDaMarkdown`; source paths follow (`Sources/TaDaMarkdown`, `Tests/TaDaMarkdownTests`). `InlineSpanDensityTests`' corpus fingerprint leaves module names out.

## Changes from 0.13.0
Each change is marked `Ta Da fork` in the source, which is the modification notice Apache-2.0 asks for. Tests: `Tests/TaDaMarkdownTests/TaDaForkTests.swift`.

1. **Alternative checkboxes.** `Parser/TaskMarker.swift` defines the accepted markers: `[ ]`, `[x]`, `[X]` plus the [Alternative Checkboxes Reference Set](https://github.com/damiankorcz/Alternative-Checkboxes-Reference-Set). As in GFM and Ta Da's `CheckboxSyntax`, a box follows the list marker after one to four spaces or tabs and needs a space or tab after it; the bullet and ordered-marker caret helpers read it the same way. The `.taskCheckbox` attribute holds the marker character (a `String`) instead of a `Bool`. `TaskCheckboxStyle` maps each marker to an SF Symbol, an optional tint, strikethrough, click transition and right-click menu entry. A `draw` closure, when set, draws every box (on the page and in the menu) instead of the symbols. Struck items' text is `mutedText`.
2. **Checkbox size and spacing.** `TaskCheckboxStyle.sizeScale` and `contentGap` set the box size and its gap from the text. The hidden spacer after `-` is kerned so the box fits the bullet slot.
3. **Bullets by depth.** `ListStyle.bulletSymbolNames` (circle.fill, circle, square.fill, diamond.fill, cycling) and `bulletSymbolScale` replace the fixed `•`.
4. **Tab / Shift-Tab** (`Input/MarkdownListIndent.swift`). These act on every selected list line plus its children. Tab only nests an item under a previous sibling. The edits are whitespace-only and go in one undo group. On a quote line they edit the whitespace after the `>` markers, among lines at the same quote level.
5. **Obsidian wiki-link aliases.** `[[Target|alias]]` resolves, links and reports clicks by `Target`. Upstream treats the part after `|` as an opaque id.
6. **Theme.** `MarkdownEditorTheme` is `Equatable` and has `selectionBackground`. The theme sets NSTextView's `linkTextAttributes` and `selectedTextAttributes`. A theme change in `updateNSView` restyles in place, so the editor isn't rebuilt.
7. **Bindings follow SwiftUI updates.** Upstream kept the text binding, `isWikiLinkActive` binding and `onLinkClick` from `init`. An embedder that switches documents by passing a new binding therefore had every later edit written into the first document, and the editor snapped back to the unchanged text. `NativeTextViewCoordinator.refresh` runs on every update. `publish` captures the binding and document when it schedules each async write.
8. **Right-click on a task box.** `NativeTextView.menu(for:)` checks for a box before `super`. AppKit's right-click moves the caret onto the line, which reveals the raw `[ ]` and removes the box. With `NativeTextViewWrapper.onTaskMarkerMenu` set, the click goes there instead of the built-in `NSMenu`: `TaskMarkerMenuRequest` carries the marker, the box's screen rect and a `setMarker` that ignores a box whose text has since changed.
9. **Undo and redo reach the binding.** On macOS 27 a TextKit 2 `NSTextView` doesn't post `NSTextDidChangeNotification` for undo or redo (TextKit 1 does), so an undone edit stayed in the bound text and was saved. The coordinator observes each per-document undo manager and runs `textDidChange` after an undo or redo that didn't trigger it.
10. **Slash commands** (`TextView/Coordinator/NativeTextViewCoordinator+SlashCommand.swift`). A `/` typed at a line start or after whitespace, outside code, opens a query. `onSlashCommandChange` reports it (`SlashCommandState`: the `/query` range, the query, whether it starts the line, and the `/`'s screen rect) as it changes, and `nil` when a space, `/` or caret move ends it. While it's open, `onSlashCommandKey` gets ↑/↓ and ↵/⇥, and esc closes it. `SlashCommandProxy.insert` replaces the `/query` in one undo step and sets the selection. The embedder draws the menu.
11. **Compiler warnings.** `BlockScopedTokenizer` (`let first`), `ContextMenu` (`#selector` for the font panel) and `NativeTextViewCoordinator+TextDelegate` (two unused `blockLatexTokens` locals removed). Not marked in the source.
12. **Serial header tests.** `ScrollingHeaderControllerTests` is `.serialized`: its animation tests spin the main run loop, and run in parallel they miss their targets.
13. **Lists in blockquotes.** A quote line whose content is a list item (`> - [ ] a`, `> 1. b`) is also parsed as one, in `BlockNode.blockquote`'s `items`, and styled as a list item inside the quote: bullet or checkbox, hanging indent and strike, one list level in from the quote's text. The items take the list line height and the quote's line spacing, so the bar stays unbroken. The task and bullet caret helpers accept the `>` prefix, and bullet depth counts from after it. Quoted ordered items keep their source numbers. Return continues a quoted item inside the quote (`> - [ ] `); on an empty one it leaves `> `.
14. **The embedder reaches the text view.** `SlashCommandProxy.textView` is the editor's `NSTextView`, for edits the embedder makes itself (Ta Da's Add Subtask).
15. **Inline bubbles** (`Configuration/InlineBubble.swift`, `Renderer/MarkdownTextLayoutFragment+InlineBubbles.swift`). `InlineCodeStyle.bubble`, or an extension's `bubble(theme:)`, draws a span as a rounded fill (optional 1pt ring and text colour) once per line it wraps onto. The `.markdownInlineBubble` attribute covers the span with its markers; hidden markers are kerned to the bubble's padding plus margin. Its edges come from the line's glyph runs: caret offsets put half a kern before the next character.
16. **Callouts** (`Parser/Callout.swift`, `Styling/MarkdownASTStyler+Callouts.swift`, `Renderer/MarkdownTextLayoutFragment+Callouts.swift`, `TextView/NativeTextView/NativeTextView+Callout.swift`). With `configuration.callouts` set, a quote line `> [!type]` (optionally `+`/`-` and a title) that starts a deeper quote level opens an Obsidian callout over the following lines at its level or deeper. Each line's `.calloutLine` says which panel slices, bars and title parts the fragment draws; the embedder supplies tints and icons. The title's `[!type]` hides behind the icon unless the caret is on the line. A `-` callout's body shrinks to 0.1pt lines unless the caret is in it. A click on a foldable title row outside the title text folds or opens it on screen (`calloutFoldOverrides`, cleared on a document switch). A right-click on a title line goes to `NativeTextViewWrapper.onCalloutMenu` (`CalloutMenuRequest`: set the type or fold sign as one undo step, and ring the callout until `close`). A restyle widens to every quote its paragraphs touch. A theme change also copies `inlineCode`, `extensions` and `callouts`. A panel ending the document draws its bottom padding below the fragment, and the editor's height counts it.
17. **A caret after inline code is outside it.** `MarkdownDetection.isInsideCodeBlock` treated the position just after a closing backtick as inside, so Return at the end of `- a `x`` didn't continue the list.
18. **Auto-closed pairs** (`Input/MarkdownAutoPairs.swift`). Bracket, `[[` and formatting-marker completion moved here from `MarkdownListHandler`. `ListStyle.autoCloseFormattingEnabled` (off by default) pairs `*`, `**`, `_`, `__`, `~~`, `==` and `` ` `` between words and outside code; a single `*` at a line's start stays a bullet, a second marker in an empty pair lengthens it, one past the longest leaves the run unpaired, and a space in an empty marker pair removes the closer. `ListStyle.autoCloseWikiLinksEnabled` (on by default) gates `[[` → `[[]]`. `NativeTextView.autoPairs` remembers each added closer: `shouldChangeText(inRanges:replacementStrings:)` moves the pairs with every applied edit and forgets them on undo or redo, and a selection outside a pair forgets it. Typing a remembered closer steps over it.

19. **iOS.** The package builds for iOS 26. `Platform/Platform.swift` names the AppKit and UIKit types the shared code uses (`PlatformColor`, `PlatformFont`, `PlatformTextView`…) and gives `UITextView` AppKit's edit and selection calls (`shouldChangeText`, `didChangeText`, `currentSelectedRange`…), so parsing, styling, layout, input, the coordinator's restyling and the formatting actions are shared. Formatting actions moved out of `ContextMenu.swift` into `MarkdownFormatting.swift`; `TaskMarkerMenuRequest` and `CalloutMenuRequest` into `MenuRequests.swift`. `DirectiveFontTransform.traits` is `PlatformFontDescriptor.SymbolicTraits`. The text-delegate path is shared (`+TextDelegate.swift`) behind thin AppKit (`+AppKitDelegate.swift`) and UIKit delegate methods. The rest of the AppKit view layer is macOS-only. `TextView/iOS/` holds the iOS editor: a TextKit 2 `UITextView` (`NativeTextView`), a SwiftUI wrapper with a scrolling header, and per-document undo. On iOS, `PlatformFont.named` maps the system font's private names to the system font. Task boxes and callout title lines are hit-tested and edited in `EditorHits.swift`, shared: macOS clicks and right-clicks call it, and on iOS a tap toggles a box (`onTaskCheckboxToggle` reports it) or folds a callout, and a press and hold sends `onTaskMarkerMenu` or `onCalloutMenu`. A hardware keyboard's Shift-Tab outdents and ↑/↓/↵/esc drive an open slash menu; `SlashCommandProxy.indent()` and `outdent()` serve a formatting bar. Tests that drive the AppKit view layer are macOS-only (33 files); the rest run on both; `IOSEditorInputTests` type, tap and press on the iOS editor, and `IOSEditorRenderTests` renders it to a PNG (`TADA_RENDER_DIR`).

## Known test failure
`MarkdownHTMLRendererTests` "bare URLs and emails autolink" fails on macOS 27: the system link detector no longer links a scheme-less `www.example.com`. It passes on macOS 26. The HTML renderer writes the rich-text flavour when the editor copies.
